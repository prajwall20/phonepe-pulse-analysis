## 🚀 Project Overview

The **PhonePe Pulse Data Analysis** project focuses on extracting, transforming, and analyzing digital payment data to uncover valuable insights into transaction trends, user behavior, and insurance adoption across India.

This project demonstrates a complete **data analytics pipeline**, including:
- Data Extraction (JSON)
- Data Transformation (ETL)
- Database Integration (MySQL)
- Data Analysis (SQL + Python)
- Visualization & Dashboard (Streamlit)

---
🔗 [App Link](https://phonepedashboard.streamlit.app/)
## 🎯 Objectives

✔ Analyze transaction trends across states and time  
✔ Identify top-performing regions and categories  
✔ Understand user behavior and device usage  
✔ Explore insurance adoption patterns  
✔ Generate business-driven insights

---

## 📊 Key Insights

📈 Digital payments saw exponential growth after 2020  
🏆 Maharashtra, Karnataka, Tamil Nadu lead in transactions  
📱 Android devices dominate user base (Xiaomi, Samsung)  
💸 Peer-to-peer transactions are most frequent  
🛡️ Insurance adoption is growing but still underpenetrated  
🌍 Urban regions dominate; rural areas show high growth potential
